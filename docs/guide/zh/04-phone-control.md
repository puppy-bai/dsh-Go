# 手机操控

让 DSH 看屏幕、帮你点按和输入，在你的手机上完成任务，随时可以暂停或停止。手机操控只在本机引擎可用，安全模式下不加载。

## 开启

<!-- nav: commonSettings,hubSettingsPhoneControl -->
`设置 › 手机操控` · [打开](dshgo://open/phone)

1. 打开页面顶部的开关。第一次会说明读取哪些内容、发给谁，点**同意并开启**。开关时，运行中的引擎会重启，正在生成的回复会中断。
2. 在**准备**里，**无障碍服务**一行点**去开启**，在系统无障碍设置里打开「DSH 手机操控」。侧载安装的 App 打不开时，点**无障碍开关点不动？**，按品牌查看「允许受限制的设置」的做法。
3. **通知**一行点**去开启**，在应用信息里允许通知。确认卡和停止按钮要用到它。
4. 点**读一下当前屏幕**，看看 DSH 能读到什么。这次读取不会发给模型。

执行任务时，屏幕上的文字会发给你选的模型；用能看图的模型时可能附截图。银行卡号、身份证号会先打码。

## 自动恢复无障碍

<!-- nav: commonSettings,hubSettingsPhoneControl,a11yRestoreTitle -->
`设置 › 手机操控 › 自动恢复无障碍`

在 **准备** 中打开这一项，阅读说明后点 **授权并开启**。已连接的 Shizuku、Sui、root 或自连 ADB 可以完成授权（页面会写明这次走哪条）；没有可用连接时，先按页面准备，或把页面的授权命令复制到电脑执行一次。只有手机操控开关开启、系统授予权限时才尝试恢复。

通过 Shizuku（含 Sui）或自连 ADB 授权时，会重新检查 App 是否实际取得权限。通道未能完成请求、系统明确拒绝本次授权，以及请求已响应但权限仍未取得，会显示不同的说明；明确拒绝不会显示成 ADB 未连接。Shizuku 或自连 ADB 的临时授权连接结束后可能正常关闭，不代表本次授权失败。系统拒绝时，不保证改用电脑命令就能成功。

授权后，在系统设置里单独关掉无障碍，DSH Go 会尝试把它重新打开；要停止手机操控，请在 DSH Go 里关闭顶部开关。恢复只修改 DSH Go 自己的服务项，保留其他无障碍服务。

被系统强制停止后，必须重新打开 DSH Go 才能恢复。持续崩溃或系统拦截时会逐渐延长重试间隔，最长约 10 分钟。此授权不保证 App 永远在后台存活，也不能修复导致服务崩溃的问题。

## 让 DSH 做事

回到对话，直接说要做的事。任务进行中：

- 保持亮屏、解锁。熄屏会停止任务。
- 密码、验证码、付款和系统设置都由你来（除非在下面的「解除限制」里开启）。遇到需要你操作的步骤，屏幕上会出现**需要你来操作**，完成后点**继续**。因为这些规则交还时，卡片标题会写明原因，比如**密码和验证码需要你来输入**、**系统设置需要你来操作**。
- DSH 连续 3 分钟没有新的操作，任务自动结束。

定闹钟、建日程、导航、分享这类操作不需要打开无障碍。

## 悬浮条

任务开始后，屏幕顶部出现悬浮条。它有三种样子，点一下就在它们之间变：

- 胶囊（默认）：一行写着 DSH 正在做的事，比如「点「发送」」，右边是**暂停**和**停止**。**暂停**后按钮变为**继续**，点它让 DSH 接着做。
- 卡片：点胶囊上的那行字展开，能看到正在操作的应用、是否免确认、最近几步，还能在插话框里告诉 DSH 换个做法。几秒不碰会收回胶囊。
- 小球：点胶囊左端的圆点，或卡片里的**收成小球**，收成贴边的小球。点小球展开；拖动它，松手吸到屏幕边，下次还在那里。**按住小球 1 秒可直接停止**，会先绕小球画一圈，中途松手就取消。

需要你确认时，胶囊写着「等你在下方确认」，确认卡出现在屏幕底部。

在手机操控页的**悬浮条**里调整（开启手机操控后显示）：

- **闲置时不透明度**：胶囊或小球 3 秒不碰时变淡到的程度，30% 到 100%，默认 70%。碰一下就恢复；卡片和等你处理的时候不会变淡。打开**闲置时自动收起**时，胶囊不变淡、直接收成小球，由小球变淡。
- **闲置时自动收起**：默认关闭。打开后，胶囊闲置几秒就收成小球，需要你确认时自动展开。
- **完成后返回 DSH Go**：默认开启。这一轮回复结束时，如果 App 在后台，会尝试回到那个对话看结果。系统限制后台弹出时，可从通知返回，见下面的「后台确认与返回」。

不论怎么设置，这一轮回复结束时悬浮条都会关闭。

## 停止

- 悬浮条上的**停止**，或按住小球 1 秒。
- 手机操控页「正在操作手机」卡上的**停止**。
- 通知栏里引擎通知上的**停止手机操控**。同一条通知上的**停止引擎**会停掉整个引擎。

停止手机操控时，本机引擎上所有进行中的回复都会一起停止。

## 确认方式

<!-- nav: commonSettings,hubSettingsPhoneControl,phoneConfirmTitle -->
`设置 › 手机操控 › 确认方式`

- **每次都询问**（默认）：进新 App、发送、删除、付款前先问你。
- **本任务免确认**：每个任务只问一次。确认卡上选**允许，本任务不再询问**，本任务剩下的步骤直接做。
- **始终免确认**：从不询问，直接操作。开启前会再确认一次。

首次启动时勾选「手机操控」，同意说明后会先选一次：**关键步骤先问我**（即每次都询问）或**全程自动**（即始终免确认），之后在这里随时可改。

确认卡 30 秒不选按**拒绝**处理。无论哪种方式，系统设置和权限页面、密码和验证码、DSH Go 自身都由你来操作，除非在**解除限制**里开启；「不碰」名单里的 App 在**应用名单**里调整。确认方式下方会列出这几条，并带着两处的入口。

## 后台确认与返回

<!-- nav: commonSettings,hubSettingsPhoneControl,phoneBackgroundGuideTitle -->
`设置 › 手机操控 › 后台确认与返回`

手机操控开启后，这一行在手机操控页的**进阶**里，点它可以重新查看说明。点**打开系统设置**会打开 DSH Go 的系统应用信息页。

需要你确认时，DSH Go 会显示卡片；卡片不可用时，会尝试发通知或回到 App。请在系统设置中允许手机操控通知和弹出提醒。部分手机还提供「后台弹出界面」权限，允许后可改善自动返回；菜单名称随系统版本变化。

任务完成后没有自动返回，点通知里的**任务完成 · 查看结果**。如果通知或后台弹出被系统拦住，手动打开 DSH Go 查看结果。打开**完成后返回 DSH Go**不代表系统一定允许自动返回。

## 应用名单

<!-- nav: commonSettings,hubSettingsPhoneControl,phoneAppRulesTitle -->
`设置 › 手机操控 › 应用名单`

为每个 App 选**不碰**、**每一步都确认**或**照常**。支付、银行、券商类 App 默认**不碰**，微信默认**每一步都确认**；没列出的 App 照常处理，敏感操作仍先问你。放宽规则时会说明风险，确认**我知道风险，仍然修改**后生效。点**添加 App** 可以按包名添加。

## 操作记录与进阶

**最近操作**记下每一步，不含屏幕内容；点**全部记录**查看。记录只保存到 App 关闭为止。

**进阶**里：

- **不打扰模式**：在看不见的屏幕上操作，不耽误你用手机。需要 Android 14 及以上。在 **通道** 里选一条：装了 Shizuku App 用 Shizuku；Magisk 或 KernelSU 装了 Sui 模块用 Sui；已 root 的手机用 Root（点「用 Root 开启」后由 root 管理器弹窗授权，在这之前不会执行 su）；都没有就用自连 ADB。点开一条看检查项，按页面完成准备，再点「用 … 开启」；页面会标出建议的那条，但不会替你选。用 Shizuku 或自连 ADB 时要连接 Wi-Fi、保持无线调试开启；仍需保持亮屏、解锁。开启后，「正在使用」下面有个「保持 … 通道」开关，默认关：打开后，连接断开、重新打开 App 或重启手机时，DSH Go 会自己把这条通道连回来，不用再回来重选；没打开时，重启手机后要回来重新激活。「保持 root 通道」意味着 DSH Go 会自己再向 root 管理器申请，给不给仍由 root 管理器决定；Shizuku 和 Sui 只用已有的授权、等它们的服务运行，自连 ADB 只用已有的配对。在系统里被强制停止过的 App，开机后不会自己恢复，打开一次 DSH Go 即可。
- **后台运行**：防止系统关掉无障碍，打开手机设置指南。
- **后台确认与返回**：让确认卡和任务结果及时出现，见上面的「后台确认与返回」。

## 自动任务：保存和重复运行

手机操控页里的自动任务把一段已知流程交给手机本地执行。等待、条件分支和有限循环无需每一步请求 AI；页面判断、视觉定位和修复仍需要模型。旧的单次手机操作工具继续可用。

1. 在聊天中说明目标、允许的 App、参数和停止条件，让 AI 先观察页面，再生成 schema 1 任务。也可在任务页导入 JSON；导入只产生待审核任务。
2. 检查待审核任务的完整流程、应用和限制。可以先确认仅运行一次；这不会保存任务或授予长期权限，待审核任务仍保留。
3. 确认流程有复用价值后再保存。为每个参数填写允许免确认的值，或明确允许所有符合该参数定义的值。选择每次确认或长期授权；修改流程需要审核新版本。
4. 已保存任务可在任务页填写参数启动，也可在聊天中让 AI 按任务 ID 调用。超出已批准参数范围时需你本次确认，不会自动扩大长期范围。

全局自动模式由你开启，重启后保留，直到手动关闭；它跳过已批准范围内任务的运行确认。任务声明的应用、参数范围、应用名单、系统权限和禁止动作仍然有效。关闭全局自动模式不会撤销单个任务的长期授权。

同一时间只运行一个本地自动任务。手动暂停、切换到范围外 App、锁屏或读屏中断时，应先核查页面，再从任务页选择继续或停止；继续会重新读屏。进程退出后的记录显示中断，不自动重放。发送、提交等操作可能已生效但结果无法证实时，显示 `result-uncertain`，本版不能直接继续该次运行；请核查真实结果后停止，再生成剩余流程，防止重复发送。

修复整次任务累计最多两轮；修复只能使用原应用和能力。成功修复不会静默覆盖保存的任务，需要你审核新版本。运行摘要保留最近 7 天且最多 100 条；摘要不保存消息、屏幕文字或 AI 提示词。任务定义和你明确保存的参数值本身会保存在本机。

## 本机截图证据

自动任务页的“本机截图证据”默认关闭，由你确认后开启。开启后，可保存显式 `snapshot` 节点、AI 按需读图和失败时采集的截图。需要结果证据时在 `finish` 前加入 `snapshot`；并非每次完成都会自动生成结果帧，也不是全程录屏。

截图只保存在本机，不自动外发。每次运行最多 10 张，全部截图合计最多 50MB、保留最多 7 天。在任务页点缩略图可放大查看；文件缺失时如实提示。截图可能含私人内容，分享前请自己检查。

关闭开关停止后续留存，已有截图仍在。“清理截图证据”确认后删除全部已存截图，保留任务、文字结果及开关设置。模型工具不会获得本机截图文件列表。

## 任务 JSON 格式

下面是只读模板，`example.phone.lab` 是占位包名，不能直接代表浏览器或任意 App。先用实际读屏和应用列表确认包名、可见文字与页面前提，再替换。格式校验通过不表示手机上的页面可以执行。

```json
{
  "schema": 1,
  "id": "local-check",
  "name": "本地页面只读验收",
  "apps": ["example.phone.lab"],
  "steps": [
    {"op": "snapshot"},
    {"op": "wait", "text": "DSH 手机操控验收页", "timeoutMs": 10000},
    {"op": "assert", "text": "DSH 手机操控验收页"},
    {"op": "finish", "result": {"status": "verified"}}
  ],
  "limits": {"timeoutMs": 60000, "maxActions": 10, "maxAiCalls": 0}
}
```

顶层必填 `schema: 1`、`id`、`name`、`apps` 和非空 `steps`。可选 `parameters`、`limits`、`capabilities`、`description`、`forbiddenTargets`；版本由保存流程递增。任务最多声明 10 个 App、200 个定义节点、4 层嵌套。不能执行任意 JavaScript、shell 或 Auto.js 脚本。

| 动作 | 必要字段及含义 |
| --- | --- |
| `open` | `app`：预先声明的应用包名 |
| `tap`、`type` | `target` 可见文字或 `selector`；`type` 还需 `text` |
| `observe`、`snapshot` | 读取当前页，无其他必填字段 |
| `read_text` | `target` 或 `selector`，`name` 保存为本次变量 |
| `scroll` | `direction` 为 up/down/left/right；可带 `until` 文字及 `max`，上限 20 |
| `key` | 本版仅 `key: "back"` |
| `tap_xy`、`input` | 最近一次观察的 `observation`、`x`、`y`；`input` 还需 `text` |
| `assert` | `text`：当前可见文字条件 |
| `wait` | `ms` 固定等待，或 `text` 加 `timeoutMs` 等到文字出现；二选一 |
| `if` | `condition`、`then`，可选 `else` |
| `repeat` | `count` 为 1–100，`steps` 为循环体；可选 `until` 条件在每轮开始前判断 |
| `break` | 结束当前循环 |
| `set` | `name`、`value` 设置本次变量，不能覆盖启动参数 |
| `ai` | `prompt` 请求 AI 判断，可用 `name` 接收返回值 |
| `plugin` | `tool` 为实际已安装工具名，`arguments` 为已声明参数；等待真实插件回执 |
| `finish` | 可选 `result`，结束任务并返回结果 |

`condition` 可写 `{"text":"已完成","match":"contains"}`，或 `{"variable":"done","equals":true}`；`not: true` 取反。文字匹配支持 `contains`（包含）、`exact`（某行完整匹配）和 `normalized`（折叠空白后包含），不支持正则表达式。步骤可带 `requireText` 作为前置文字条件、`expect` 作为后置文字条件；写操作后验证失败会按结果不明确处理。

`parameters` 按名称声明 `type` 为 string/integer/number/boolean，可用 `default`、`required`、`enum`、`min`、`max`、`maxLength`。例如 `{"message":{"type":"string","required":true,"maxLength":100}}`。`${message}` 引用参数或先前生成的本次变量；完整引用保留原类型。插件参数只能引用已声明启动参数，不能借本次变量更换收件人或操作目标。

`capabilities` 省略时从定义动作推导。AI 后续补充的动作也必须已声明能力；例如后续需要点按和输入，应预先列出 `"capabilities":["observe","tap","type"]`。能力不会取消应用和参数限制。`forbiddenTargets` 用于列出不可点按的目标；有禁止目标的任务不接受坐标操作，因为无法证明坐标避开了禁止按钮。

`limits` 的 `timeoutMs` 为主动运行时间，普通任务默认 10 分钟、上限 30 分钟；`continuous: true` 默认 60 分钟、上限 120 分钟。暂停时间不计入；`wait` 计入。`maxActions` 默认及上限均为 500，统计原生写动作和插件节点；`maxAiCalls` 普通默认及上限为 20，连续任务为 50，可设为 0。这个字段统计 AI 检查点，不能等同于模型请求数或 token 费用；一个检查点可能需要多轮模型请求。固定等待上限 120 秒，文字等待上限 30 秒。

## 聊天工具与视觉定位

`mcp__phone__task` 的 `action` 可用 `list/get/validate/propose/start/status/pause/resume/stop/ai_result/repair`；其中恢复需要用户在任务页操作，模型不能自行批准恢复。保存、修改授权和全局模式也只能由你在 App 中确认。

AI 使用 `validate` 检查定义，`propose` 提出待审版本，`start` 运行已保存任务。任务到达 AI 节点时处于 `awaiting_ai`，状态中提供 `runId`、`checkpoint` 和 `kind`；AI 可用 `get` 加当前 `runId` 读取该次定义和绑定参数，必须先核查现场，再用同一检查点提交 `ai_result` 或 `repair`。暂停或停止后，旧检查点失效；修复的 `steps` 描述剩余流程，不表示重放已执行动作。

本版没有本地 OCR 保证。普通可截图页面无可用文字树时，需支持图片输入的模型通过截图判断，并使用有效观察编号定位；截图清楚不等于任意坐标都允许操作，应用规则、禁止目标、系统保护与观察过期检查仍可能拒绝。没有图像能力的模型不能完成这条视觉回退路径。

美团、拼多多、课程播放等任务还取决于真实页面和账号状态。应把停止点、候选数量、课程章节、答题范围写进定义；不要把模板校验、定时等待或模型口头报告当作下单、实际播放、课程记进度或答题正确的证据。本版不含定时、通知触发、开机运行或音量键触发。
